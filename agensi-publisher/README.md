# Agensi Publisher

Publish AI agent skills to the Agensi marketplace end-to-end — signup,
profile, ZIP submission, security-scan fixes, and updates.

A step-by-step SKILL.md guide for any creator listing their first skill.
Includes the pitfalls discovered through real submissions: verification
email issues, stale form data, the 8-point security scan's network-access
rejection, and the update flow.

## Why this skill exists

Agensi grew from one registry (Dec 2025) to several major marketplaces by
2026 — and the publishing process has quirks nobody documents. This skill
captures them so you don't have to trial-and-error your way through:

- Google SSO workaround for the broken verification email
- Stale dashboard checklist vs real payout status
- The security scan's "undeclared network access" rejection and the exact fix
- The dual update flow (GitHub instant vs Agensi re-approval)

## Usage

Drop this SKILL.md into any SKILL.md-compatible agent (Claude Code,
Codex CLI, Cursor, Gemini CLI, OpenCode, Hermes, and 20+ more). When you
say "publish my skill to Agensi", the agent follows the procedure.
