# Chat Games

Turn any chat into game night. A collection of text-based games you can
play with your AI agent — no boards, no downloads, just conversation.

## Games included

| Game | How it works |
|---|---|
| **20 Questions** | You think of something, the agent guesses (or vice versa) |
| **Hangman** | ASCII gallows, word guessing, both directions |
| **Word Ladder** | Change one letter at a time from start to end word |
| **Anagrams** | Unscramble the word, or stump the agent |
| **Trivia** | 6+ categories, scoring, easy to hard |
| **Riddles & Logic** | Classic brain teasers with hints |
| **Text Adventure** | Interactive stories — you pick your path |
| **Story Dice** | Random elements woven into a tale |
| **Would You Rather** | Diabolical either/or dilemmas |

## How to use

Drop this SKILL.md into any SKILL.md-compatible agent (Claude Code,
Codex CLI, Cursor, Gemini CLI, OpenCode, Hermes, and 20+ more), then
just say:

> "Fancy a game?"
> "Play hangman with me"
> "Let's do a text adventure — spaceship theme"
> "Quiz me on science, medium difficulty"

The agent becomes game master — tracks score, keeps state, and plays
fair.

## Why

Games are a great way to:
- Kill time during a break
- Test your agent's reasoning
- Discover the fun side of your AI
